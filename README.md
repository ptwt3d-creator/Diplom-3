# Дипломный проект: UI-автоматизация Stellar Burgers

## Структура проекта и описание файлов

### Архитектура и Page Objects (Слой страниц)
`base_page.py` (`BasePage`, `CommonPage`) — базовый класс архитектуры. Содержит методы-обёртки над явными ожиданиями Selenium (`visibility`, `clickable`, `invisibility`), реализованный нативный JavaScript-скрипт для стабильного Drag and Drop ингредиентов, универсальный метод безопасного клика `js_wait_click` в обход анимационных оверлеев React, а также общие элементы навигации шапки сайта.

`main_page.py` (`MainPage`) — класс главной страницы конструктора бургеров. Содержит бизнес-логику управления ингредиентами, открытия/закрытия модальных окон деталей, а также шаги оформления и подтверждения заказов.

`list_order_page.py` (`OrderPage`) — класс страницы Ленты заказов. Отвечает за получение текстовых значений динамических счётчиков выполненных заказов (за все время, за сегодня) и валидацию списков активных заказов «В работе».

`login_page.py` (`LoginPage`) — класс страницы авторизации пользователя. Хранит метод заполнения учётных данных и выполнения сквозного логина на сайт под тестовым аккаунтом.

`data.py` (`Urls`) — конфигурационный файл. Хранит базовые URL-адреса и прямые ссылки на эндпоинты разделов Ленты заказов и окна авторизации.

`conftest.py` — глобальный файл конфигурации PyTest. Управляет жизненным циклом и масштабом (scope) драйверов браузера, а также автоматически инициализирует объекты страниц Page Object (`MainPage`, `OrderPage`, `LoginPage`) перед прогоном тестов.

`locators/` — пакет с изолированными файлами локаторов элементов (включая `base_page_locators.py`) для разделения логики страниц и путей поиска в DOM.

---

### Тестовые наборы (Test Suites)
`test_main_functionality.py` (`TestMainFunc`) — тесты основного UI-функционала главной страницы: проверка успешного открытия модального окна деталей при клике по ингредиенту и его корректного закрытия по нажатию на крестик.

`test_navigation.py` (`TestNavigation`) — тесты сквозных переходов интерфейса: проверка валидности редиректа пользователя из конструктора на страницу Ленты заказов и обратно по кнопкам шапки.

`test_list_orders.py` (`TestListOrder`) — комплексные интеграционные тесты Ленты заказов: валидация увеличения локального счётчика ингредиента при переносе в корзину, динамическая проверка увеличения глобального счётчика заказов «Выполнено за все время» и «Выполнено за сегодня» после покупки, а также отображение созданного номера заказа в блоке «В работе».

## Инструкция по запуску тестов

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3. Находясь в корневой директории проекта, установите все необходимые зависимости и внешние библиотеки одной командой:
```bash
pip install -r requirements.txt
```

### 2. Кроссбраузерный запуск тестов с перезапусками (Reruns)
Для обеспечения стабильности прогона тестов на анимированном React-интерфейсе настроен автоматический перезапуск упавших сценариев. Перед запуском команды укажите требуемый веб-драйвер (`webdriver.Chrome()` или `webdriver.Firefox()`) внутри вашего `conftest.py`.

Запуск тестов с автоматическим перезапуском до 3 раз и таймаутом ожидания растворения оверлеев в 1 секунду:
```bash
python -m pytest --reruns 3 --reruns-delay 1 tests/
```

## Генерация раздельных отчетов Allure

Все тестовые сценарии детально размечены аннотациями `@allure.suite`, `@allure.sub_suite`, `@allure.title` и `@allure.description`.

1. Сбор результатов и генерация отчета для **Google Chrome**:
   *(Убедитесь, что в `conftest.py` активен Chrome)*
   ```bash
   python -m pytest --alluredir=results_chrome --reruns 3 --reruns-delay 1 tests/
   allure generate results_chrome --clean -o report_chrome
   ```

2. Сбор результатов и генерация отчета для **Mozilla Firefox**:
   *(Смените в `conftest.py` драйвер на Firefox)*
   ```bash
   python -m pytest --alluredir=results_firefox --reruns 3 --reruns-delay 1 tests/
   allure generate results_firefox --clean -o report_firefox
   ```

По окончании прогона в корневой папке проекта сформируются два независимых интерактивных HTML-отчета: `report_chrome` и `report_firefox`. Для локального просмотра любого отчета в браузере используйте команду:
```bash
allure open report_chrome
```
